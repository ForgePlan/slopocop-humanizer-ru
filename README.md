# ForgePlan/slopocop-humanizer-ru — Russian Text Humanizer Skill

Strips AI-generation markers from **Russian** text and rewrites it into living authorial prose — 54 patterns, HARD BANS, a fact-lock, and a deterministic 0–100 cleanliness scanner.

> **Attribution.** This is a mirror of **humanizer-ru by [ilyautov](https://github.com/ilyautov/humanizer-ru)** (MIT). Full credit to the original
> author — ForgePlan only re-publishes it for `npx skills add` convenience as part of the
> [slopocop](https://github.com/ForgePlan/marketplace) anti-slop family. The original license is
> preserved; no authorship is claimed.

## Install

```bash
# Global (recommended):
npx skills add ForgePlan/slopocop-humanizer-ru -g

# Project-only:
npx skills add ForgePlan/slopocop-humanizer-ru
```

Installs as `humanizer-ru`.
